## 维度判定：`hybrid`

轨迹本身共面（2D 足够），但"速度分解"这件事在 3D 里可以被看见——
用户转动视角后能确认：`vₓ` 始终水平、`v_y` 单调变化，两者互不干扰。
所以标 `hybrid` 而不是 `3d`（宪法第四条：不为 3D 而 3D）。

---

## 需求

| ID | 需求 | 验收 |
|---|---|---|
| REQ-P-001 | 水平方向匀速，`vₓ` 恒定 | 任意两时刻差值 < 1e-12 |
| REQ-P-002 | 竖直方向匀变速，`v_y = v₀sinθ − gt` | 最高点处 `\|v_y\| < 1e-9` |
| REQ-P-003 | 机械能守恒 | 相对误差 < 1e-9 |
| REQ-P-004 | 射程 `R = v₀²sin2θ/g`（h₀=0） | 误差 < 1e-6 |
| REQ-P-005 | 45° 射程最大 | 45° > 60°，45° > 30° |
| REQ-P-006 | 落地后不下穿地面 | `y >= 0` 在所有 t |
| REQ-P-007 | 落地时刻 `t = (v_y0 + √(v_y0²+2gh₀))/g` | 与积分结果一致 |

## 教学陷阱

1. 认为"最高点速度为零"——最高点只有竖直分量为零，水平分量不变；
2. 把射程公式当成万能——`R=v₀²sin2θ/g` 只在 `h₀=0` 时成立；
3. 认为"重的球先落地"——真空中与质量无关（这也是需要 `assumptions` 的地方）。

## 非目标

- 不做空气阻力（若要做，需换数值积分求解器，且失去解析解的可验证性）
- 不做地面反弹（留给后续"碰撞"场景）
