## 1. 为什么必须真 3D（hybrid）

感应电流的方向**垂直导轨平面**（−z，向里）。平面图上第三维只能画成"点/叉"，
学生背"左力右电"式口诀，却不知道反的是哪根轴。3D 里把 B（竖直向下）、
v（水平向右）、I（垂直纸面向里）三根正交矢量同时立起来，转一下视角才能看清
右手定则到底在三个方向之间建立了什么关系。

主体是平面装置（导轨 + 棒 + 磁场框），但**核心矢量离开该平面**——
dimension 因此标 `hybrid`（参照 `thin-lens` 的先例）。与高中 `induction`
（F-010，磁铁插线圈·楞次定律）的边界：初中只讲"条件 / 方向 / 大小"，
BLv 作为读数出现；高中讲磁通量与磁通变化，两份场景各挂各的章节。

## 2. 物理模型

匀强磁场区 $x \in [0, 3]$（B 竖直向下 $-\hat{y}$），导体棒垂直置于导轨上、
以 $v$ 沿 $+\hat{x}$ 匀速切割磁感线：

$$
\varepsilon = B\,L\,v \cdot \mathbb{1}_{x<3},\qquad
I = \frac{BLv}{R},\qquad
F = B\,I\,L,\qquad
F\,v = I^{2}R
$$

- $F\,v = I^2 R$ 是**能量平衡**：机械功率全部变成焦耳热——楞次定律"阻碍"的
  定量形式，也是本场景最值得讲的一条（默认参数下 0.045 W = 0.045 W）。
- $I_0 = BLv/R$ 是守恒读数：与位置无关。离开磁场只是"条件不满足"，
  不是公式失效——HUD 用它防止学生以为"公式时灵时不灵"。
- 方向：$v \times B = \hat{x} \times (-\hat{y}) = -\hat{z}$（见 §5 修正记录）。

## 5. 迁移修正记录（重要）

来源 `lessons/初中物理实验/05-electromagnetic-induction.html` 的数值已由
`verify_junior.py` 手算验证，但**感应电流方向画反了**：

- 原页面几何：棒竖直（沿 y）、v 沿 +x、B 竖直向下（−y）、I 箭头沿 **+z**。
- 但 $v \times B = \hat{x}\times(-\hat{y}) = -\hat{z}$，且验证安培力：
  I 沿 +z 时 $\hat{L}\times\hat{B} = \hat{z}\times(-\hat{y}) = +\hat{x}$，
  安培力**顺着**运动方向给棒助力——感应电流在对外做功，违反能量守恒与楞次定律。
- 修正为 I 沿 **−z**（垂直纸面向里）：此时 $\hat{L}\times\hat{B} = -\hat{x}$，
  安培力阻碍运动 ✓，且 $F\,v = I^2 R$ 精确成立。
- 期望值不受影响（lessons 只验数值大小 150 mA，方向从未被验证）。

> 教训：与 F-018 同源——数值验证不等于物理验证。**方向、符号、单调性**
> 这些"定性正确"的维度，必须按物理重新推一遍。原页面 26 项数值全过，
> 却在符号上错了一个与能量守恒同等级的问题。

## 6. 可视化构成

- **磁场区**：紫色方框边界（x ∈ [0,3]）
- **导轨**：两条水平线（y = ±0.85）
- **导体棒**：黄色粗线，随 x 移动
- **矢量**：B（蓝，−y，两个锚点）、v（粉，+x）、I（绿，−z，离开磁场即隐藏）
- **读数**：x / inF / ε / I / I₀（守恒，绿色）
