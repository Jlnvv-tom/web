## 维度判定：`2d`

成像公式与三条特殊光线完全共面，3D 只是"能转着看的一张图"。标 `2d` 是诚实：
这个场景的 3D 价值来自「光屏位置可拖、像会跟着变清晰」，而不是空间关系。

---

## 需求

| ID | 需求 | 验收 |
|---|---|---|
| REQ-T-001 | 成像公式 `1/u + 1/v = 1/f` | 残差 < 1e-12 |
| REQ-T-002 | 放大率 `m = −v/u` | 误差 < 1e-12 |
| REQ-T-003 | `u = 2f` → 倒立等大实像 | `v = 2f`, `m = −1` |
| REQ-T-004 | `u < f` → 正立放大虚像 | `v < 0`, `\|m\| > 1` |
| REQ-T-005 | `u = f` → 不成像（平行出射） | `meta.kind = 'none'` |
| REQ-T-006 | 实像画三条特殊光线 | `lines.ray0/ray1/ray2` 存在 |
| REQ-T-007 | 虚像只画两条 + 反向延长线 | `lines.virtual0/1` 存在，`ray2` 不存在 |
| REQ-T-008 | 像高 `h' = m·h` | 误差 < 1e-12 |

## 教学陷阱

1. 把虚像当成"不存在的像"——虚像是眼睛能看到的，只是光线的反向延长线交点；
2. 记混 `u`/`v` 的正负号规则——本项目统一用"实正虚负"；
3. 认为"物越近像越大"——`u < f` 时才成立，`u > f` 区间内是物近像远像变大。

## 非目标

- 不做球面镜
- 不做厚透镜与像差
- 不做多透镜组合（望远镜/显微镜，规划中）
