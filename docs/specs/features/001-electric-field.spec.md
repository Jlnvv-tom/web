## 1. 背景

竞品调研的结论是：现有产品把「电场」讲成了 2D 平面图 + 一句"电场线不相交"。
但电场是**空间中每一点都有值**的矢量场，而学生看到的第一张图永远是切面——
于是"电场线是平面上的几条曲线"这个错误表征被永久固化。

同时「等势面与电场线垂直」在纸面上只能靠背，而在 3D 里它是一个可以**转着看**的几何事实。

**为什么必须真 3D**：立体场线让"场充满空间"可见；转动视角时，场线与等势线的垂直关系
在透视下依然成立，这比任何静态插图都有说服力。（宪法第四条）

---

## 2. 用户故事

1. 作为高二学生，我想把一个正电荷和一个负电荷放在一起，看看电场线到底从哪里出发、到哪里结束。
2. 作为学生，我想把电荷换成同号，看到中间的"中性点"，并理解"场强为零≠电势为零"。
3. 作为学生，我想放一个静止的试探电荷，验证"它不会沿着电场线走"。
4. 作为教师，我想把 q、d 拖到极端值，确认画面不会崩、读数不会 NaN。

---

## 3. 物理模型

两个点电荷置于 xz 平面（`y = 0`）的 x 轴上：

```
q₁ at (-d/2, 0, 0)        q₂ at (+d/2, 0, 0)
```

| 量 | 公式 | 说明 |
|---|---|---|
| 电势 | `V(P) = k Σ qᵢ/rᵢ` | 标量叠加，`k = 8.99×10⁹` |
| 场强 | `E(P) = k Σ qᵢ r̂ᵢ / rᵢ²` | 矢量叠加 |
| 试探电荷受力 | `F = qₜ E` | |
| 运动方程 | `m r̈ = qₜ E(r)`，`m = 1 kg` | 示教量级 |
| 机械能 | `E_mech = ½mv² + qₜV(r)` | 静电场保守 → 守恒 |

**软化半径** `ε = 1e-4 m`：`r → 0` 时 `1/r²` 发散，用 `r² + ε²` 替代 `r²`。
该近似在 `r > 0.05 m` 时相对误差 < 1e-5，不影响教学。

## 4. 需求与验收

### REQ-E-001 · 场线追踪（RK4 流线积分）
沿 `dr/ds = Ê(r)` 用 RK4 积分，弧长步长 `h = 0.22 m`，最多 700 步。

验收：
- 场线上任意点的单位切向量与 `Ê` 的夹角余弦 `> 0.999`（覆盖 ≥ 20 个采样点）；
- 从正电荷出发的场线必须终止于负电荷，或离开计算域（`|r| > 24 m`）。

### REQ-E-002 · 种子分布（平面 / 立体双模式）
- `mode = 'plane'`：在每个电荷周围半径 `0.45 m` 的圆上取 32 个等角种子（xz 平面内）；
- `mode = '3d'`：用 Fibonacci 球面取 26 个方向，半径 0.45 m。

验收：两种模式下的场线条数分别为 32±2 / 26±2（同号电荷两边都发线，异号时负电荷一侧的
反向追踪线被去重）。

### REQ-E-003 · 负电荷反向追踪与去重
从负电荷沿 `−Ê` 反向追踪：若最终抵达正电荷，则该线与已有线重复，丢弃；否则反转后保留
（表示"来自无穷远"的场线）。

验收：等量异号（q₁=+3, q₂=−3）时，不存在一条"两端都在负电荷"的线。

### REQ-E-004 · 等势线（marching squares）
在 `y=0` 平面取 132×132 网格（`x,z ∈ [-14, 14]`），对每个电平做 marching squares，
再把线段拼接成折线。

电平取 `±V₀·{0.25, 0.5, 0.9, 1.6, 2.6, 4.2, 6.8}`，`V₀ = k·max|qᵢ| / d`。

验收：等势线上任意点的电位与标称电平的相对误差 `< 2e-3`（线性插值 + 网格分辨率决定）。

### REQ-E-005 · 场线 ⊥ 等势线
取等势线上若干点，用双线性法求 `∇V`，验证 `|∇V × Ê| < 0.02`。

验收：这是本特性最重要的几何断言——它直接对应"等势面与电场线垂直"这条教材结论。

### REQ-E-006 · 试探电荷动力学
从参数点 `(pr, pa)` 静止释放，RK4 积分 `dt = 0.004 s`，最长 3.2 s。
`sample(t)` 按 `t` 在预计算轨迹上插值（定点重放，保证可回退，符合 REQ-SV-001）。

验收：
- 机械能漂移 `|ΔE/E| < 1e-2`（3.2 秒内）；
- 在单电荷情形下，轨迹与场线重合（"沿场线走"的直觉只在此时成立）。

### REQ-E-007 · 场强不为零但电势可为零
`q₁ = −q₂` 时，中垂面（`x = 0`）上 `V = 0`，但 `E ≠ 0`。

验收：在中垂面取 5 个点，`|V| < 1e-6` 且 `|E| > 0.1`。

### REQ-E-008 · 同号电荷的中性点
`q₁ = q₂ = +q` 时，原点处 `E = 0`（对称性），但 `V = 2kq/(d/2) ≠ 0`。

验收：`|E(0)| < 1e-9`，`V(0) > 0`。

### REQ-E-009 · HUD 读数
至少 6 项，其中 `ME`（机械能）标 `constant: true`，用于"守恒量可视化"。
读数在任意参数下不得为 `NaN` / `Infinity`。

验收：遍历参数边界组合（8 组），所有 `scalars` 值有限。

### REQ-E-010 · 讲解脚本
8 步，覆盖：现象 → 场线方向 → 转视角看立体 → 换同号看中性点 → 等势线 → 垂直关系 →
试探电荷偏离场线 → 总结。至少 1 次 `camera` 变化、1 次 `params` 变化、末步 `pause: true`。

### REQ-E-011 · 内容配额
`formulas ≥ 3`、`pitfalls ≥ 4`、`quiz ≥ 3`、`assumptions ≥ 2`。

### REQ-E-012 · 参数死值检测
拖动任意滑块，`SceneState` 必须可见变化（几何或读数至少一项）。

验收：对每个 slider，比较 `min` 与 `max` 两次求解的 `linesets` 长度或 `scalars` 值，
至少 1 项不同。

## 5. 非目标

- ❌ 等势**面**（3D 曲面网格）：等势面只在 `y=0` 平面上以等势线呈现，`assumptions` 里明确声明。
- ❌ 导体/介质/感应电荷：只做真空中的两个点电荷。
- ❌ 三个及以上电荷：留给 F-005 之后的「平行板电容器」。
- ❌ 相对论/量子修正。
- ❌ 让用户用鼠标拖动电荷：本期用滑块控制 `d`，拖动交互留给后续迭代。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 立体场线太密，画面糊 | 首屏劝退 | 默认 26 条 + 低透明度；`plane` 模式作为"看清结构"的降级选项 |
| marching squares 产生大量碎段 | draw call 爆炸 | 线段拼接成折线，单帧上限 60 条 |
| 试探电荷被电荷"捕获"后停住 | 用户以为卡了 | `meta.probeState = 'captured'`，HUD 显示状态；轨迹保留 |
| 极端参数下等势线挤成同心圆 | 视觉噪声 | 电平按 `V₀` 归一化，随 `d` 与 `q` 自适应 |
