## 1. 背景

波动这一章最大的误解只有一句：**「波把质点搬走了」**。

学生会这么想是有道理的——看到的确实是「波形在向右移动」。教材的破解方式是加一句
「质点只在平衡位置附近振动，不随波迁移」，但这句话和眼睛看到的画面是**矛盾的**：
波形明明在走。矛盾的根源在于，静态图里「波形」和「质点」是同一个东西的两张脸，
没法分开看。

第二难的是驻波：「两列反向传播的波叠加」——课本画两列反向的箭头，然后直接给出
驻波的包络图。中间那一步「叠加」是从来没被演示过的。

---

## 2. 为什么必须（/不必）真 3D

`dimension: 3d`。

破解「波把质点搬走了」需要**同时**给出两样东西：整条波形在平移，以及**某一个质点**的
运动轨迹是一条**竖直线段**。在平面图上这两条线会重叠成一团；在 3D 里可以把质点轨迹
画在波形所在的平面之外，转一下视角就能看到「波形沿 x 走、质点沿 y 上下」这两件事
互不干扰。

驻波同理：包络（橙色虚线）和绳子（青色实线）在平面图里是两条挤在一起的曲线，
在 3D 里可以清楚地看到绳子在包络内部「呼吸」、而包络本身不动。

---

## 3. 用户故事

1. 作为学生，我想锁定一个质点，看到它只在原地上下、不跟着波形走。
2. 作为学生，我想看到「下一时刻的波形」的灰色虚线，确认波形整体在平移。
3. 作为学生，我想切换成驻波，看到波形不再前进，而是原地"呼吸"。
4. 作为学生，我想看到节点处位移恒为 0、波腹振幅是单列波的 2 倍。
5. 作为学生，我想确认 `v = λf`，且改变频率只影响快慢、不影响波形疏密的比例关系。

---

## 4. 物理模型

绳子沿 x 轴，长 4 m，离散成 25 个质点；振动沿 y。

| 量 | 公式 | 备注 |
|---|---|---|
| 行波 | `y = A sin(kx − ωt)` | 沿 +x 传播 |
| 反向行波 | `y = A sin(kx + ωt)` | 沿 −x 传播 |
| 驻波 | `y = 行波 + 反向行波 = 2A sin(kx) cos(ωt)` | 波腹振幅 `2A` |
| 波速 | `v = λf` | |
| 角频率 / 波数 | `ω = 2πf`，`k = 2π/λ` | |
| 周期 | `T = 1/f` | |
| 质点最大速度 | 行波 `Aω`；驻波波腹 `2Aω` | |
| 节点位置 | `x = n·λ/2` | 位移恒为 0 |

**时间平移的等价关系**：`y(x, t+Δt) = y(x − v·Δt, t)`。这是「波形在平移、质点不迁移」
的数学表述，也是本场景最重要的一条可测性质——它同时否定了「质点被搬走」。

**参数边界**：`λ ≥ 0.4 m`（再短的话 25 个质点采样不足，波形会出现锯齿假象）；
`A ≥ 0.02 m`；`f ≥ 0.05 Hz`。

## 5. 需求与验收

### REQ-WAV-001 · 基本关系
`v = λf`、`T = 1/f`、`ω = 2πf`、`k = 2π/λ`。

验收：四式分别与闭式解一致（< 1e-12）。

### REQ-WAV-002 · 波形整体平移
`y(x, t+Δt) = y(x − v·Δt, t)`。

验收：取 5 组 `(x, Δt)`，两边误差 < 1e-9。

> 这条是本场景最重要的一条：它同时证明了「波形在走」和「质点不走」。

### REQ-WAV-003 · 质点最大速度 = Aω
验收：数值差分与 `Aω` 一致（< 1e-6）。

### REQ-WAV-004 · 质点不随波迁移
验收：任一质点的 x 坐标在整个周期内恒为常数（< 1e-12）。

### REQ-WAV-005 · 同一时刻波形是正弦
验收：一个波长内恰好完成一次全振动。

### REQ-WAV-006 · 节点处位移恒为 0
验收：`x = n·λ/2` 处，遍历多个 `t`，`|y| < 1e-12`。

### REQ-WAV-007 · 波腹振幅 = 2A
验收：驻波的最大 `|y|` 与 `2A` 一致（< 1e-9）。

### REQ-WAV-008 · 驻波不传播（包络不动）
验收：遍历 `t`，`|2A sin(kx)|` 的包络值与 `t` 无关（< 1e-12）。

### REQ-WAV-009 · 驻波 = 两列反向行波叠加
验收：`standingY(x,t) === travelY(x,t) + reverseY(x,t)`，逐点误差 < 1e-12。

### REQ-WAV-010 · 节点个数与 λ 相关
验收：`λ` 减半 → 节点数翻倍（在绳长内）。

### REQ-WAV-011 · 讲解脚本
≥ 8 步，覆盖「质点不迁移 → 波形平移 → v=λf → 切驻波 → 包络 → 节点波腹 → 反向行波叠加」。

验收：至少 1 次相机变化、1 次模式切换、末步 `pause: true`。

### REQ-WAV-012 · 内容配额
`formulas ≥ 4`、`pitfalls ≥ 4`、`quiz ≥ 3`、`assumptions ≥ 4`。

## 6. 非目标

- ❌ 纵波（疏密波）——本期只做横波，在 `assumptions` 里声明。
- ❌ 波的反射、折射、衍射与干涉图样（另开场景）。
- ❌ 波的能量传播与能流密度。
- ❌ 真实的绳子动力学（张力、波速由介质决定）：本场景的 `v = λf` 是**运动学关系**，
   不是由张力推导的动力学结果——这一点必须写进 `assumptions`，否则会造成新的误解。

## 8. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 质点太稀疏，波形看起来是锯齿 | 视觉假象，反而强化"折线波"误解 | 波形用 160 段细采样曲线画，质点只作为离散标记（25 个） |
| `λ` 太小导致一个波长内不足 2 个质点 | 采样失真 | `λ` 下限 0.4 m（此时一个波长约 2.5 个质点，仅为下限） |
| 学生把 `v = λf` 当成"波速由频率决定" | 新的误解 | `assumptions` 中明确：介质决定波速，频率由波源决定，`λ` 是被决定的量 |
| 驻波包络在行波模式下为空 | 契约测试报断链 | 求解器返回空数组 + 场景标 `optional: true` |

## 9. 开发过程中抓到的真 bug

1. **反向行波误写成 `travelY(−x)`**：初版驻波用 `travelY(x,t) + travelY(−x,t)` 实现。
   `travelY(−x, t) = A sin(−kx − ωt)`，这确实是一列反向传播波，但它的**初相是错的**——
   叠加结果仍然是驻波，节点位置却整体偏移了，与 `2A sin(kx)cos(ωt)` 对不上。
   修正方式是老老实实另写一个 `reverseY(x,t) = A sin(kx + ωt)`。
2. **包络拆成上下两条折线**：驻波包络 `±2A sin(kx)` 如果只画一条 `|2A sin(kx)|` 的折线，
   视觉上是一条贴着 x 轴的"馒头波"，完全看不出"上下边界"的意思。改成 `envUp` / `envDown`
   两条折线分别渲染后，包络才真正成为一条能框住绳子的边界。
3. **契约测试报 "env-up 点数不足"**：行波模式下包络不存在，求解器返回空数组。
   契约测试原本只把 `undefined` 当作合法缺省，空数组被判为断链。修法是**两侧都改**：
   契约测试接受 `!line || line.length === 0`（两者都是"不存在"的合法形式），
   场景文件给这两个对象标 `optional: true`——这才是 `optional` 这个字段的本意。
