## 1. 背景

「像在镜子后面」是初中物理最典型的**背下来了但没懂**的知识点。教材的画法是：镜前画一个
物体，镜后画一个对称的虚像，中间画几条虚线，配一句「像与物关于镜面对称」。学生记住了
结论，但心里一直有个没解开的问题：**镜子后面什么都没有，那个像到底在哪儿？**

这个疑问的答案是——虚像**就是**反射光线的反向延长线的交点。这不是比喻，是几何事实。
但演示这件事需要把「镜前实线」和「镜后虚线」画成一条连续的光路，而平面图上镜面是一条
线，镜前镜后挤在同一个二维平面上，根本分不开。

---

## 2. 为什么必须（/不必）真 3D

`dimension: 3d`，而且这是全部场景中 3D 价值最硬的一个——决定性的理由是**镜面转动**。

平面镜成像里最经典的一道题是「镜面转 θ，反射光线转 2θ」。镜面一旦倾斜，光路就离开了
原来的竖直平面，反射点跑到 `z ≠ 0` 的地方。这时候：

- 平面图**根本没有 z 轴可用**，只能假装还在一个平面里，于是"2θ"变成了需要硬记的结论；
- 3D 里转一下视角，能直接看到反射光线绕法向扫过两倍的角，光路离开了原来的平面。

「像在镜后、光路在镜前」这个空间关系，也只有在能转动视角时才是**看到**的，而不是被告知的。

---

## 3. 用户故事

1. 作为学生，我想看到入射光线、反射光线、法线三者，并确认两个角相等。
2. 作为学生，我想看到镜后那条**虚线**是反射光线的反向延长线，从而理解「虚像」的"虚"字。
3. 作为学生，我想把镜子转一个角，看到反射光线转**两**个角，并看到反射点离开原平面。
4. 作为学生，我想把眼睛挪到别的位置，看到像不动——像是物的对称点，与观察者无关。
5. 作为学生，我想确认像距 = 物距、像高 = 物高，且像是正立的。

---

## 4. 物理模型

镜面过原点，法向 `n = [cosφ, 0, sinφ]`（φ 为镜面绕 y 轴的转角）。物在 `−x` 侧，眼睛也在 `−x` 侧。

| 量 | 公式 | 备注 |
|---|---|---|
| 反射定律 | 入射角 = 反射角，三线共面 | 两角都相对**入射侧那一支法向**测量 |
| 反射方向 | `d' = d − 2(d·n)n` | |
| 反射点 | 把眼睛关于镜面对称得 `E'`，直线 `P→E'` 与镜面的交点 | 光路可逆的几何解 |
| 像 | 物点关于镜面的对称点 | `p' = p − 2(p·n)n` |
| 像距 | `= 物距`（沿法向） | |
| 像高 | `= 物高`，正立 | |
| 镜转 2θ | 镜面转 `φ` → 反射光线转 `2φ` | 入射方向固定时成立 |

**为什么用「眼睛的对称点」求反射点**：这样求出的交点同时满足「入射角 = 反射角」和
「光路可逆」两件事，是几何解而不是数值解。反过来先求角再解方程会引入符号歧义。

**边界**：`|dir · n| < 1e-9`（光线与镜面平行）时反射点不存在，返回 `null`，场景降级为
不画反向延长线——此时 `meta.hit === false`，UI 必须给出提示而不是画一条错误的光路。

## 5. 需求与验收

### REQ-REF-001 · 入射角 = 反射角
验收：`φ ∈ {0°, 15°, 30°, 45°}` 下两角之差 < 1e-9 度。

### REQ-REF-002 · 三线共面
入射光线、反射光线、法向矢量三者共面。

验收：混合积 `|d_in · (d_out × n)| < 1e-9`。

### REQ-REF-003 · 反射点落在镜面上
验收：`|r · n| < 1e-9`（到镜面的距离为 0）。

### REQ-REF-004 · 光路可逆
物体与眼睛互换后，反射点不变。

验收：两次计算的反射点距离 < 1e-9。

### REQ-REF-005 · 像距 = 物距，像在镜后
验收：`imgDist === u`；像点的法向分量与物点反号。

### REQ-REF-006 · 像高 = 物高，正立
验收：`imgHeight === h`；像的底端到顶端方向与物的同向。

### REQ-REF-007 · 像与物关于镜面对称
验收：中点落在镜面上；连线平行于法向。

### REQ-REF-008 · 虚像永远在镜后
验收：遍历 `φ ∈ [−60°, 60°]`、`u ∈ [0.5, 4]`，像的法向分量恒与物反号。

### REQ-REF-009 · 镜面转 φ，反射光线转 2φ
这是本场景的核心 3D 价值点。

验收：`φ` 取 0°/10°/20°/30°，反射方向相对基准的转角 `= 2φ`，误差 < 1e-9。

> 入射方向必须取**垂直于 y 转轴**的方向（如 `[-1, 0, 0.25]`）。若入射光带 y 分量，
> 「镜面绕 y 转 → 光线转 2φ」这个命题本身就不成立，测出来的偏差是命题用错了，不是 bug。

### REQ-REF-010 · 镜面倾斜后反射点离开原平面
验收：`φ ≠ 0` 时 `|r.z| > 1e-3`（这就是 3D 不可替代的证据）。

### REQ-REF-011 · 讲解脚本
≥ 8 步，覆盖「反射定律 → 虚像的虚字 → 像距物距 → 观察者无关 → 镜转 2θ → 离开平面」。

验收：至少 1 次相机变化、1 次参数变化、末步 `pause: true`。

### REQ-REF-012 · 内容配额
`formulas ≥ 4`、`pitfalls ≥ 4`、`quiz ≥ 3`、`assumptions ≥ 4`。

## 8. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 入射/反射角用了相反的法向 | 「入射角 ≠ 反射角」，定律直接崩 | 两个角统一取**入射侧**法向的锐角（见 §9 真 bug 1） |
| 大转角下反射点飞出镜面 | 光路画在镜子外面 | 镜面长度参数 `mirrorH` 可调；超出时 `meta.hit` 提示 |
| 光线与镜面平行 | 除零 → NaN | `|dir·n| < 1e-9` 时返回 `null`，场景降级 |

## 9. 开发过程中抓到的真 bug

1. **入射角与反射角用了相反的法向**：初版 `angles()` 对入射光取 `+n`、对反射光取 `−n`
   （"因为反射光在另一侧"），算出 177° 和 2.5°——**反射定律当场崩掉**。
   课本的定义是两个角都相对**入射侧那一支法向**测量，两者都是锐角。
   修正方式是统一对 `cos` 取绝对值再 `acos`。这个 bug 的教训是：**物理量的定义要先于
   几何直觉**，觉得"反射光在另一侧所以该用反向法向"正是典型的用直觉压定义。
2. **2θ 测试的入射光带 y 分量**：测试 "镜面转 φ、反射光转 2φ" 一直挂。查下来不是代码错，
   是**命题的适用条件**：镜面绕 y 轴转，只有入射光垂直于 y 轴时反射光才恰好转 2φ。
   把测试入射光改成 `[-1, 0, 0.25]` 后通过。这说明测试挂掉时第一反应应该是
   「是不是我测的命题本身有条件」，而不是「是不是代码算错了」。
3. **镜面画成了一条水平线，且只有 1.6 m 高**：`mirror` 折线的两个端点是
   `tangent * mirrorH/2`，而 `tangent` 当时是 `(sinφ, 0, −cosφ)`——躺在 xz 平面里。
   于是"竖直的镜子"被画成了地面上的一条横线；同时 1.6 m 的板高接不住 y≈1.3 m 处的
   反射点，**光路打在空气里却照样被画出来**。改成：薄板高度 2.4 m、从地面立起
   （`mirrorC = [0, H/2, 0]`），折线只作为"镜子站在哪儿"的地脚线。
4. **薄板的 `rotation.y` 符号写反**：盒子默认法向 +x，绕 y 转 θ 后是 `(cosθ, 0, −sinθ)`，
   而镜面法向是 `(cosφ, 0, sinφ)`，因此 `rotationY` 必须是 `−φ`。符号反了镜面会朝
   反方向倾——画面上只差几度，看起来"差不多"，但几何全错。已由求解器直接输出
   `mirrorRotY = −φ`，场景只负责绑定，不让渲染层自己算。
