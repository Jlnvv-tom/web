## 为什么必须真 3D

`F = qv×B` 的结果垂直于 `v` 与 `B` 张成的平面。这个"垂直于两个方向"的关系，
在 2D 图上只能靠标注文字欺骗观众；只有在 3D 里转动视角，才能确认 F 始终躺在同一平面内。

## 已识别的教学陷阱（对应 pitfalls）

1. 把 F 画成"顺着 B"——叉乘的结果必然垂直于两个因子；
2. 以为磁场对粒子做功——`F⊥v ⟹ P=0`；
3. 受力分析时多画一个"向心力"——向心力是洛伦兹力扮演的角色，不是新的力；
4. 认为周期与速度有关——这是回旋加速器能工作的前提。

## 非目标

- 不做相对论修正（v ≪ c）
- 不做磁场边界与非匀强磁场
