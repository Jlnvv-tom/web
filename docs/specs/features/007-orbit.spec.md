## 1. 背景

开普勒三定律里最反直觉的是**第二定律（面积定律）**。「相等时间扫过相等面积」这句话，
在任何平面图上都是一句需要相信的断言：教材画一个近日点的瘦扇形、一个远日点的胖扇形，
然后说「它们面积相等」——学生的实际反应是「看起来明明不相等」。

原因是：扇形面积相等这件事**必须靠同时摆出来比**才有说服力。静态图永远只能给出「一个
时刻一个扇形」，而面积定律讲的是一个**速率**（dA/dt 恒定），速率不可能画在一张静图里。

---

## 2. 为什么必须（/不必）真 3D

`dimension: 3d`。

两件事只有 3D 能说清：

1. **面积定律**：把当前扫过的扇形和远日点附近的参照扇形**同时**摆在轨道上，两者的形状
   差异一目了然（一个矮胖、一个瘦高），而它们的面积读数相同。转视角还能看到这两个扇形
   确实躺在同一平面内——「共面」本身就是椭圆轨道的性质。
2. **焦点**：中心天体在椭圆的**一个焦点**上，另一个焦点是空的。这个「偏心」的空间关系
   在正视图里完全看不出来，只有斜着看才能感受到「太阳不在中心」。

---

## 3. 用户故事

1. 作为学生，我想同时看到近日点和远日点的两个扇形，并确认它们面积相等。
2. 作为学生，我想看到行星在近日点跑得快、远日点跑得慢，且与 `r·v` 的守恒对上。
3. 作为学生，我想拖动 `a` 看到 `T` 按 `a^{3/2}` 变化，并确认它跟 `e` 无关。
4. 作为学生，我想把 `e` 拖到 0，看到轨道变成圆、速率恒定——"圆是椭圆的特例"这件事。
5. 作为学生，我想加入第二颗行星，直观看到 `a` 差 4 倍时周期差 8 倍。

## 4. 物理模型

椭圆轨道，中心天体位于原点（= 椭圆的一个焦点），轨道平面为 xy。

| 量 | 公式 | 备注 |
|---|---|---|
| 开普勒方程 | `M = E − e·sinE` | 牛顿迭代求解，24 次内收敛 |
| 位置 | `[a(cosE − e), a√(1−e²)·sinE, 0]` | 原点在焦点 |
| 日心距 | `r = a(1 − e·cosE)` | |
| 速率（活力公式） | `v = √(GM(2/r − 1/a))` | |
| 第三定律 | `T = 2π√(a³/GM)` | 与 `e` 无关 |
| 面积速率 | `dA/dt = ½√(GM·a(1−e²))` | 恒定 |
| 比耐能量 | `v²/2 − GM/r = −GM/(2a)` | 单位质量守恒量 |
| 近日/远日速率比 | `v_p / v_a = (1+e)/(1−e)` | 活力公式的推论 |

**场景时钟口径（重要）**：本求解器的 `duration()` 与 `t` 的单位是**地球年**，不是秒。
物理周期以秒算是 3.16e7，直接上时间轴会让读数变成一长串没有意义的数字。这个口径是本
求解器的私有约定，**必须写进规格**——否则 `invariants()` 里 `dA/dt` 的单位换算会对不上。

`YEAR = 365.25 × 86400 s`，面积读数换算成 `AU²/年` 输出（原始值是 1e22 量级，不可读）。

**参数边界**：`e` 截断到 `[0, 0.85]`（`e → 1` 时开普勒方程的条件数爆炸，且轨道会跑出
视野）；`a` 下限 0.05 AU；`M` 下限 0.02×10³⁰ kg。

## 5. 需求与验收

### REQ-ORB-001 · 开普勒方程求解正确
`E − e·sinE = M`。

验收：`e = 0.85` 时残差 < 1e-12；`e ∈ {0, 0.3, 0.6, 0.85}` 全覆盖。

### REQ-ORB-002 · 第一定律：轨道是椭圆，中心天体在焦点
验收：轨道上任意点到两焦点距离之和 `= 2a`（误差 < 1e-9）。

### REQ-ORB-003 · 近日点 / 远日点
验收：`r(0) = a(1−e)`、`r(π) = a(1+e)`。

### REQ-ORB-004 · 圆轨道退化
`e = 0` 时 `r` 与 `v` 都恒定。

验收：`e = 0` 遍历一圈，`r` 与 `v` 的极差 < 1e-9。

### REQ-ORB-005 · 轨道共面（z = 0）
验收：所有轨道点 `|z| < 1e-12`。

### REQ-ORB-006 · 第三定律
`T = 2π√(a³/GM)`；地球参数下 `T ≈ 1 年`；`a` 变 4 倍 → `T` 变 8 倍；`T` 与 `e` 无关。

验收：三条分别断言，比值精确到 9 位。

### REQ-ORB-007 · 第二定律：面积速率恒定
近日点附近和远日点附近的两个扇形，单位时间面积相等。

验收：`invariants().areaRateError` 与 `areaRateErrorFar` 均 < 1e-6。

> 必须**同时**测近、远两端：只测一端等于没测。这两个数是这条定律唯一的硬证据。

### REQ-ORB-008 · 面积速率闭式解
`dA/dt = ½√(GM·a(1−e²))`，读数单位 `AU²/年`。

验收：数值积分结果与闭式解误差 < 1e-6。

### REQ-ORB-009 · 活力公式与能量守恒
`v = √(GM(2/r − 1/a))`；`v²/2 − GM/r = −GM/(2a)`。

验收：`invariants().energyDrift < 1e-12`；`v_p/v_a = (1+e)/(1−e)`。

### REQ-ORB-010 · 平近点角连续（无跳变）
`M(t)` 必须是**连续**函数，不能对 `t/T` 取整。

验收：一整周期后回到出发点；相邻采样点位移小于轨道周长的 1%。

> 这条抓到过真 bug：初版写了 `Math.round(t/T × 2π)`，行星以 1 弧度为步长**跳**着走。

### REQ-ORB-011 · 讲解脚本
≥ 8 步，覆盖「椭圆与焦点 → 面积定律 → 第三定律 → 圆轨道退化 → 活力公式 → 双行星对比」。

验收：至少 1 次相机变化、1 次参数变化、末步 `pause: true`。

### REQ-ORB-012 · 内容配额
`formulas ≥ 4`、`pitfalls ≥ 4`、`quiz ≥ 3`、`assumptions ≥ 4`。

## 8. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 大偏心率下牛顿迭代不收敛 | 行星位置跳变 / NaN | `e` 截断 0.85；`e ≥ 0.8` 时用 `E₀ = π` 作初值 |

| 时间单位混乱（秒 vs 年） | `dA/dt` 单位错、守恒量对不上 | 在规格里写死口径，`invariants()` 内部显式乘 `YEAR` |

## 9. 开发过程中抓到的真 bug

1. **平近点角取整导致行星跳变**：初版 `M = Math.round((t/T)·2π)`。本意是"对齐到整周期"，
   实际效果是行星每帧只在 1 弧度的整数倍上出现，看起来像在**传送**。改成连续取模后正常。
   这里的教训是：**为了"对齐"牺牲连续性，永远是错的**。
2. **面积用首尾两点算三角形，低估 40%**：面积定律的数值验证最初只取扇形首尾两个端点
   加原点构成三角形。当扇形张角较大（这里是 45°）时，弧线明显在三角形外面，
   实测偏差 40%——大到足以让"面积相等"看起来是错的。改成 512 段的鞋带公式后降到 1e-6 以下。
3. **时间单位不一致**：`duration()` 返回年、`areaRate()` 返回 m²/s，两者直接相除得到的
   面积是错的 3e7 倍。修法不是改公式，是在规格里把「场景时钟单位 = 年」定死，
   并让 `invariants()` 里显式写出 `* YEAR` 的换算。
