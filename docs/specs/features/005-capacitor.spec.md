## 1. 背景

「板间是匀强电场」在课本上是一句结论 + 一张剖面图。剖面图带来的误解很具体：
学生会以为只有中间那条电场线附近的粒子才受力，偏转量与入射高度有关。

这个误解只能靠**把间隙看成一个体积**来破除——所以它必须 3D。

---

## 2. 用户故事

1. 作为学生，我想看到「加上电压 → 粒子弯掉、不加电压 → 直线飞出」的对照，从而理解电场是原因。
2. 作为学生，我想确认板间每个位置的场强都一样（偏转与高度无关）。
3. 作为学生，我想同时看到 C、Q、W 三个量随 U/d 的变化关系。
4. 作为学生，我想看到"偏转太大 → 撞板"这个真实失败模式。

---

## 3. 物理模型

两块 30 cm × 30 cm × 1.2 cm 的竖直极板，法向沿 z，间距 d，长度方向沿 x。
粒子从 x = −L/2、y = 0、z = 0 以 v₀ 沿 +x 射入。

| 量 | 公式 | 备注 |
|---|---|---|
| 场强 | `E = U/d` | 匀强，方向从正极板指向负极板（−z） |
| 加速度 | `a = qE/m` | 含 q 的符号 |
| 轨迹 | `x = v₀t − L/2`，`z = −½at²` | 抛体运动，同构 |
| 出射偏转 | `y = qEL²/(2mv₀²)` | 与入射高度无关 |
| 电容 | `C = ε₀S/d` | S = aL 固定 |
| 储能 | `W = ½CU²` | |
| 面电荷密度 | `σ = Q/S = ε₀E` | |

终止条件：`|z| ≥ d/2` → 撞板；`x ≥ L/2` → 飞出。

---

## 4. 需求与验收

### REQ-C-001 · 匀强电场
`E = U/d`，与位置无关。

验收：板间取 5 个点，`E` 完全相等（误差 < 1e-9）；`d` 减半 → `E` 翻倍。

### REQ-C-002 · 出射偏转公式
未撞板时出射偏转 `= qEL²/(2mv₀²)`。

验收：与闭式解误差 < 1e-12；`v₀` 翻倍 → 偏转变为 1/4。

### REQ-C-003 · 偏转与入射高度无关
（匀强电场的直接后果）

验收：轨迹任意时刻的 `z` 与 `−½at²` 一致（< 1e-9），与 y 无关。

### REQ-C-004 · 撞板判定
偏转量超过 `d/2` 时判定撞板，且停在板面上、尚未飞到极板末端。

验收：`end === 'hit'`，`|z| = d/2`，`|x| < L/2`。

### REQ-C-005 · 电容三量自洽
`C = ε₀S/d`、`Q = CU`、`W = ½CU²`、`σ = ε₀E`。

验收：四项互相一致；`d` 减半 → `C` 与 `E` 同时翻倍。

### REQ-C-006 · 电势零点
以负极板为 0 势点，沿 +z 线性升高，正极板处为 U。

验收：三点取值精确。

### REQ-C-007 · 机械能守恒
`½mv² + qV(z)` 全程恒定。

验收：`invariants().energyDrift < 1e-9`。

### REQ-C-008 · 方向语义
场强箭头指向 −z；正电荷受力与 E 同向、负电荷反向。

验收：正负电荷的出射 `z` 等值反号。

### REQ-C-009 · 实体极板
极板为圆角金属盒（`box` 图元），尺寸固定 30 cm × 30 cm × 1.2 cm，位置随 d 绑定。

验收：视觉内表面间距恰好是 `d`（求解器导出的是几何中心）。

### REQ-C-010 · 示意箭头自适应
板间电场箭头为示意长度（0.4d），任何参数下都不戳出极板。

验收：遍历 `d ∈ {0.2, 1, 5}`，箭头长度 ≤ 0.45d。

### REQ-C-11 · 讲解脚本
10 步，包含「U=0 对照组 → 加电压 → 匀强 → 侧面看抛物线 → 与高度无关 → 撞板 → C/Q/W → 公式」。

验收：至少 1 次相机变化、3 次参数变化、末步 `pause: true`。

### REQ-C-012 · 内容配额
`formulas ≥ 4`、`pitfalls ≥ 4`、`quiz ≥ 3`、`assumptions ≥ 4`。

## 7. 开发过程中抓到的真 bug

1. **场强方向与轨迹符号矛盾**：`Evec = [0,0,−E]` 但轨迹写成 `+½at²`，
   导致"力向左、人往右走"，能量守恒测试直接报 4e-4 漂移。修正为 `−½at²` 后漂移降到 0。
2. **极板间距多出一个板厚**：若把 box 的位置绑到"内表面"，视觉间距会变成 `d + t`。
   求解器改为导出**几何中心**（`d/2 + t/2`）。
3. **小尺度场景被全局参数坑死**：`minDistance = 1.2`、雾 42–150、尘埃半径 70 都是按
   20 m 场景调的，0.3 m 的电容器会被雾完全吞掉且无法放大。已改为按相机距离缩放。
