## 1. 背景

「简谐运动是匀速圆周运动在直径上的投影」——这句话是所有教材都会写，但**没有一本教
材能画清楚**的一句话。课本的画法是：左边一个弹簧振子，右边一个圆，中间一条虚线，配
文「你看，它们是对应的」。学生看到的是**两张互不相干的图**，对应关系靠想象。

更糟的是三个高频误解，都源于只看到「来回摆」这件事本身：

1. 以为周期跟振幅有关（摆得大就慢一点）——这是把单摆的**大角行为**错当成了简谐；
2. 以为单摆的周期跟质量有关；
3. 以为 `T = 2π√(L/g)` 和 `T = 2π√(m/k)` 是两个需要分别背的公式，看不出它们是**同一个
   `ω² = 恢复力系数 / 惯性系数`**。

---

## 2. 为什么必须（/不必）真 3D

`dimension: 3d`。

参考圆在 **xz 平面**里转，振动轴是 **x 轴**，投影线是一条竖直虚线。这三者只有在 3D 里
才可能同时在场且互不遮挡：平面图里参考圆必须被压扁成椭圆，或者把投影线画在圆的外面，
无论哪种都会让「投影」这件事看起来像是人为贴上去的辅助线，而不是几何事实。

转一下视角，参考圆上的点和振子会**沿视线方向对齐**——这一瞬间「投影」就成了肉眼可见
的事实，而不是一句需要相信的话。

## 3. 用户故事

1. 作为学生，我想看着参考圆上的点转一圈，同时振子来回一次，从而相信「简谐 = 圆周的投影」。
2. 作为学生，我想拖动振幅滑块，看到周期读数**一动不动**，从而纠正「摆得大就慢」的直觉。
3. 作为学生，我想把 g 从 9.8 改成 1.6（月球），看到单摆变慢、弹簧振子纹丝不动，从而分清
   两种振子恢复力的来源。
4. 作为学生，我想看到动能和势能在平衡位置/端点之间此消彼长、总量恒定。
5. 作为学生，我想看到摆角超过 15° 时系统明确提示「小角近似失效」——而不是假装公式还成立。

## 4. 物理模型

单摆：悬点固定在 `(0, L, 0)`，摆长 `L`，摆在 xy 平面内运动，平衡位置在悬点正下方。
弹簧：墙在 `x = −0.7`，自然长度 `0.55`，振子沿 x 轴运动。

| 量 | 公式 | 备注 |
|---|---|---|
| 角频率 | `ω = √(g/L)` / `ω = √(k/m)` | 同一个结构：`√(恢复力系数 / 惯性系数)` |
| 周期 | `T = 2π/ω` | 与振幅无关 |
| 角振幅（单摆） | `θ₀ = A/L` | 小角近似下 `sinθ ≈ θ` |
| 位移 | `x = A cos(ωt)` | |
| 加速度 | `a = −ω²x` | 简谐的定义式 |
| 恢复力 | 弹簧 `−kx`；单摆切向 `−mg sinθ` | 单摆在大角下不再严格简谐 |
| 动能 | `½mv²` | |
| 势能 | 弹簧 `½kx²`；单摆 `mgL(1−cosθ)` | 单摆的严格形式，不用 `½kx²` 近似 |
| 最大速率 | `v_max = Aω` | 出现在平衡位置 |

**近似的边界**：小角近似在 `θ₀ ≤ 15°(0.262 rad)` 时误差 < 1%。求解器在
`A > 0.35L`（约 20°）处硬截断，并在 `θ₀ > 15°` 时把 `meta.smallAngleOk` 置为 `false`
由 UI 提示。这是**唯一**允许的近似，且必须在场景的 `assumptions` 里写清楚。

## 5. 需求与验收

### REQ-SHM-001 · 周期公式
单摆 `T = 2π√(L/g)`，弹簧 `T = 2π√(m/k)`。

验收：与闭式解误差 < 1e-12。

### REQ-SHM-002 · 周期与振幅无关
这是「简谐」的定义性特征，也是最常见的误解点。

验收：`A` 取 0.05 / 0.3 时周期完全相等（< 1e-12）；两种模式都验证。

### REQ-SHM-003 · 重力只影响单摆、不影响弹簧
`g` 换成 1.6 → 单摆周期变为 `√(9.8/1.6)` 倍，弹簧振子周期不变。

验收：比值精确到 9 位小数；弹簧周期差 < 1e-12。

### REQ-SHM-004 · 运动学满足 ẍ = −ω²x
用**数值二阶导**验证（而不是把公式代进去自己验自己）。

验收：`t ∈ {0.3, 1.1, 2.7}`，`(x(t+h) − 2x(t) + x(t−h))/h²` 与 `−ω²x(t)` 差 < 1e-4。

### REQ-SHM-005 · 参考圆的 x 投影 = 振子位移
3D 演示的数学依据，必须逐点成立。

验收：`refPoint(t)[0]` 与 `displacement(t)` 在 4 个时刻相等（< 1e-12）。

### REQ-SHM-006 · 摆角振幅 = A/L
验收：`A=0.25, L=1` 时 `angleAt(0) = 0.25 rad`。

### REQ-SHM-007 · 最大速率出现在平衡位置
验收：`|v(T/4)| = Aω`（9 位小数）；`|v(0)| < 1e-12`。

### REQ-SHM-008 · 机械能守恒
`KE + PE` 全程恒定（单摆用**严格**的 `mgL(1−cosθ)`，不用 `½kx²` 近似）。

验收：`invariants().energyDrift < 2e-3`。

> 为什么容差是 2e-3 而不是 1e-9：单摆的 `x = A cos(ωt)` 本身来自小角近似，
> 与严格的 `mgL(1−cosθ)` 势能不完全自洽。`A/L = 0.25` 时二者差约 1e-3 量级，
> 这是**物理近似**的误差，不是代码 bug——把它压到 1e-9 反而是在掩盖近似。

### REQ-SHM-009 · 摆长守恒（几何自洽）
摆锤到悬点的距离恒为 `L`。

验收：`|bob − pivot| = L`，误差 < 1e-12。

> 这条测试抓到过真 bug：初版把摆锤写成 `[L sinθ, L cosθ, 0]`（以原点为圆心），
> 摆长虽然对，但平衡位置跑到了 `y = L` 而不是 `y = 0`——悬点在天上，摆却在地面附近。

### REQ-SHM-010 · 小角近似失效时诚实提示
`θ₀ > 15°` 时 `meta.smallAngleOk === false`；`A` 超过 `0.35L` 时被硬截断。

验收：`clampParams` 把越界的 `A` 拉回 `0.35L`；`assumptions` 里写明近似的适用条件。

### REQ-SHM-011 · 讲解脚本
≥ 8 步，覆盖「周期与振幅无关 → 参考圆投影 → 换弹簧模式 → 同构的 ω → 能量转化 → 近似边界」。

验收：至少 1 次相机变化、1 次模式切换、末步 `pause: true`。

### REQ-SHM-012 · 内容配额
`formulas ≥ 4`、`pitfalls ≥ 4`、`quiz ≥ 3`、`assumptions ≥ 4`。

## 8. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 学生把参考圆当成「另一个振子」 | 演示失效 | 参考圆用灰色虚线、振子用亮色实体，层级上明确区分 |
| 大角度下公式与画面不一致 | 违背宪法第三条（诚实） | `smallAngleOk` 显式提示 + `clampParams` 硬截断 |
| 两种模式切换时相机/参考圆位置突变 | 观感割裂 | 脚本在切换步显式设置相机，而不是靠插值 |

## 9. 开发过程中抓到的真 bug

1. **摆锤位置公式写错**：初版 `bob = [L sinθ, L cosθ, 0]`，等价于把圆心放在原点。
   摆长数值上是对的（所以「摆长守恒」测试差点写成能过的样子），但**平衡位置跑到了
   `y = L`**——悬点在 `(0, L, 0)`，摆却绕着 `(0,0,0)` 转，两者根本不相连。
   修正为 `bob = [L sinθ, L − L cosθ, 0]`，并补了 REQ-SHM-009 这条几何自洽测试。
2. **能量守恒容差的选择**：一开始照抄电容器的 1e-9，测试挂掉。查下来不是 bug，
   而是小角近似与严格势能之间的固有矛盾。正确的做法是把容差放宽到能**反映近似量级**
   的 2e-3，并在规格里写清理由——把近似误差藏进 1e-9 里才是真的自欺欺人。
3. **参考圆半径与振幅滑块脱钩**：早先参考圆用静态 `disc` 图元画，半径写死。
   拖振幅滑块时圆不动、振子动，"投影"关系当场崩塌。改为由求解器每帧输出 `refCircle`
   折线（半径 = 当前振幅）。
