# DJI Osmo Action 4 · 3D 拆解可视化 Demo

基于 **Three.js** 的纯前端 3D 交互页面：程序化生成 DJI Osmo Action 4 运动相机模型，支持点击部件触发拆解动画、自由旋转缩放、查看部件参数详情。

> 无任何外部 3D 模型文件、无贴图文件、无第三方框架 —— 所有几何体、贴图、环境反射均由代码在运行时生成。

---

## 快速开始

ES Module 需要通过 HTTP 访问（`file://` 直开会被浏览器 CORS 拦截）：

```bash
cd demo
python3 -m http.server 8080
# 打开 http://localhost:8080
```

或任选其一：`npx serve demo` / `npx http-server demo` / VS Code Live Server。

## 功能清单

| 功能 | 说明 |
| --- | --- |
| **程序化建模** | 16 个部件全部由代码生成：挤出圆角框、圆柱、球冠、圆环、管状曲线、Canvas 贴图 |
| **点击拆解** | 单击模型上任意部件 → 自动切换拆解视图 + 部件发光高亮 + 相机聚焦 + 右侧详情面板 |
| **拆解 / 组装** | 底部「拆解」按钮或空格键；16 个部件按索引错峰动画（easeOutCubic） |
| **自由视角** | 左键旋转 / 右键平移 / 滚轮缩放 / 单指旋转 / 双指缩放平移，带阻尼 |
| **自动取景** | 按模型包围盒投影 + 画幅比例精确计算相机距离，切换拆解状态与窗口尺寸时自动重构图 |
| **部件标注** | 3D 锚点 → 2D 屏幕投影，HTML 标签 + SVG 引线；拆解态显示全部，组装态显示选中项 |
| **一键演示** | 自动拆解后按顺序逐个讲解 16 个部件，点击任意处退出 |
| **透视模式** | 前后壳与屏幕半透明，直接观察内部堆叠 |
| **单独查看** | 详情面板「仅看此部件」，其余部件 ghost 化 |
| **操作引导** | 首次进入 4 步引导（旋转 / 拆解 / 详情 / 演示） |
| **响应式** | 桌面 / 平板 / 手机（竖屏）三档布局 |
| **快捷键** | `空格` 拆解切换 · `R` 重置视角 · `Esc` 取消选中 |

## 技术要点

- **Three.js r186**（本地 `vendor/`，离线可用），`WebGLRenderer` + ACES Filmic 色调映射
- **程序化环境反射**：用 Canvas 画一张等距柱状渐变图，经 `PMREMGenerator` 生成 IBL，金属材质（镜圈、中框、磁吸片）才有正确反射
- **带孔挤出体**：前壳 / 后盖用 `THREE.Shape` + `holes` + `ExtrudeGeometry` 一次做出「镜头孔 + 屏幕孔」的框体
- **Canvas 贴图**：DJI 标识、前后屏 UI、电池标签、PCB 走线、CMOS 光电二极管阵列、石墨烯纹、扬声器网孔、光晕、星点、接触阴影
- **选中高亮**：记录各 mesh 原始 emissive 后统一改为青色自发光 + 一个 `depthTest:false` 的 additive 光晕精灵做呼吸效果
- **拾取**：`Raycaster` + 点击 / 拖拽判定（移动 < 6 px 且时长 < 420 ms 才算点击，避免旋转时误触）

## 已知取舍

- 比例按 `1 unit = 10 mm` 建模；镜头、前屏等外观件做了风格化取舍（前屏为接近方形的扁矩形以适配 32.8 mm 机高），参数标注以官方数据为准
- 语音讲解使用浏览器 Web Speech API，物理术语发音可能不完美
- 部分部件在特定视角下会被其他部件遮挡而点不中（射线返回首个可见面），旋转视角即可
